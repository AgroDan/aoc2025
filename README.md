# Advent of Code 2025

Advent of Code is arguably one of my most anticipated events of the year. Christmas notwithstanding, with the Advent of Code challenges I can really just lose myself in the development frame of mind. I don't compete, I don't try speed runs, I only try my best at learning more about the incredible Go language. And if I happen to crunch through a puzzle quicker than expected, all the better!

This time I'm armed with GH Copilot to assist. I will _never_ use it to solve the puzzle entirely or to even explain to me how best to solve it, but if I'm ever in a jam (or at least if I don't want to have to type things over and over and over again), then it can certainly come in handy. It's been especially helpful debugging my own code!

Once more into the breach, dear friends!

## Update: Completed 12/16/25

Dan from the future, coming back to the root-level Readme to update on my completion. I managed to stay up to speed on every challenge up until [Day 10](day10/README.md). That threw me for quite a loop, but after reading up on other peoples' techniques, I re-purposed my code to utilize a new technique in my arsenal. Regardless, it set me back about 3 days. I honestly didn't know when I'd even have time to finish the rest, given the impending holidays breathing down my neck. This year's Advent of Code is half the size but just as punishing. Now with only 12 puzzles to complete, the skill curve ramps up considerably faster this time along. At this time of the challenge I'd still be dealing with some difficult puzzles but nothing too bad. Day 10 was just a beast. Not as insane as [Day 24, 2024](https://github.com/AgroDan/aoc2024/tree/main/day24), but bad enough that I lost some sleep over it.

In any case, I have successfully completed the Advent of Code challenge long before even Christmas, let alone New Years! I can now concentrate on other challenges. Maybe I should focus on the SANS holiday hack challenge again? The world is my oyster!

For what it's worth, I want to thank [Eric Wastl](https://was.tl/) for hosting this challenge. I look forward to it every year now. In my line of work it's important to understand not only the basics of development, but the algorithms and techniques that computer scientists and mathemeticians have created to solve tasks that seem so effortless in principle, but are computationally difficult. I know [Leetcode](https://leetcode.com/) is basically the advent of code all year round, but something about the whole Open Source vibe of the AOC challenges really just warms my heart.
