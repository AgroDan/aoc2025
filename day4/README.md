# Day 4: Printing Department

I don't mean to brag, but this challenge was easy. And not easy in the sense that I just breezed through it because it wasn't that many lines of code, but easy in the sense that most of the hard work I've already done in previous Advent of Code challenges. Specifically the usage of my `RuneMap` module combined with the `Coords` module. The `Runemap` module was poised specifically for challenges just like this one, where it accepts a slice of strings and chops it up into a grid that I can work with consisting of single-character runes. In this case, the characters were `@` and `.`. Simple. Then combined with the `utils.Coord` module I had written previously, I can then use the simple `GetNeighbors()` function to check in all 8 directions, which returns 8 different Coords. I then get the characters from the Coords and just check to see if there are more than `3` rolls of paper in those coords. Easy.

The next stage was only slightly more difficult, in that I had to basically pass through the entire map and modify it in place over and over again until it couldn't find any more moveable pieces, removing rolls as the rules dictate I should. I thought this was going to be fairly taxing on my CPU, but it blew through it in about `633ms`, and I think most of that was just outputting to the screen. I'll take it!
